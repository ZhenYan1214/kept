# Kept 警示規則回測資料：花蓮縣政府災害捐款專戶（真實日期序列）

整理日期：2026-10-17
用途：用台灣真實的災害捐款歷史回測 Kept 的六條公開警示規則，回答一個問題：Kept 的警示會在哪一天亮起？跟大眾或新聞發現問題的日期比，早了多少？

## 0. 讀法與原則

- **P＝一手資料**：縣府會議紀錄 PDF、縣府網站公告、收支統計表，都是本次直接下載或開啟原檔逐字核對。
- **S＝二手資料**：新聞報導。本次直接開啟原文核對過。
- **「公開日」怎麼定**：縣府網站沒有發布日誌，所以用兩個證據推定，兩者都只是**近似值**。
  - sa.hl.gov.tw 的附件檔名是上傳時間戳，例如 `202502251803…pdf` 推定為 2025-02-25 18:03 上傳。
  - PDF 內嵌的 CreationDate 是「最早可能公開日」，檔案一定是建立之後才能上網。
- **「匡列」不是「支出」**：縣府報表把委員會「匡列」（核定預留）的金額列在「支出」欄。所以報表上的「專戶餘額」不等於帳上還沒花掉的錢。本文會把「匡列數」和「實際執行數」分開寫。
- 金額照原文寫；我自己算出來的數字一律標「（計算）」。
- 「公開資料就會觸發」和「保管人依 Kept 記帳才會觸發」分開寫，見各案的回測表。

### 規則代號

| 代號 | 規則 |
|---|---|
| a | 一筆撥款（tranche）14 天內沒有被受款方確認收到 |
| b | 款項在保管人手上超過 90 天，沒有轉出，也沒有回報已付 |
| c | 受款家戶對款項提出爭議 |
| d | 申訴／陳情等待超過 14 天 |
| e | 已驗證家戶回報「還在等」，但鄉鎮或縣府回報「沒有人未獲服務」 |
| f | 基金的章程或計畫變更，或結餘被移轉 |

另外有兩條衍生檢查。它們不在 a～f 裡，但資料直接支持，供參考：

| 代號 | 規則 |
|---|---|
| g | 委員會超過作業要點規定的 6 個月沒有開會 |
| h | 公開報表內部矛盾，例如已執行數大於核定數 |

## 1. 案例一：花蓮縣 0403 地震（2024）縣府專戶

### 1.1 帳戶結構（P）

- **專戶名稱**：「花蓮縣重大災害民間賑災捐款專戶」，臺銀花蓮分行 018-038-098-191。這是**單一共用專戶**，0206 結餘、0918、0403、康芮、0923 的捐款都放在一起，用「指定捐款」科目區分。來源：https://www.hl.gov.tw/0403/cp.aspx?n=34618
- **管理規則**：作業要點 111-04-15 訂定，112-05-19、112-12-27 修正。
  - 第五點：「本會至少每六個月開會一次」。
  - 第三點：受災民眾「至多推派五人代表列席會議，並經主席同意後始得發言」。
  - 第十三點：「本專戶之收支及支用細目應定期公告」，但沒有規定頻率。
  - 來源：https://sa.hl.gov.tw/Upload/202404071635379957031.pdf ；https://glrs.hl.gov.tw/glrsout/LawContent.aspx?id=GL001170
- **委員名單**：
  - 第二屆（113-03-22～115-03-21）15 人：縣府 7 人＋學者、律師、建築師、企業代表，**沒有受災戶代表**。來源：https://sa.hl.gov.tw/Upload/202405302015014846081.pdf
  - 第三屆（115-03-22～117-03-21，名單 1150922 修）同樣沒有「受災戶代表」這個類別。社會處長由陳加富換成黃舒儀。委員蔡雲卿律師在 2026-05-14 會議上，因「同為 0403 震災集合式住宅受災戶」自行迴避，她是受災戶，但不是以受災戶代表的身分入會。來源：https://sa.hl.gov.tw/Upload/202609230857200732221.pdf ；https://sa.hl.gov.tw/Upload/202606160928010835531.pdf

## 5. 缺口與不確定處

1. **審計室原始報告沒有拿到**。審計部「總決算審核報告查詢平臺」https://auditreport.audit.gov.tw/ 有防機器人保護（Incapsula），本次沒有繞過。35.67% 等數字目前只有更生日報 2026-07-31 的轉述（文中寫「見圖1：審計室提供」）。報告發布日 2026-07-24 只來自搜尋摘要，沒有核實。另外，審計室在更早的審核通知中已經「建請」調整委員會組成，那份通知的日期也沒有取得。
2. **0403 實際執行數只有幾個時點**：2025-02-27 是 1.242 億，2026-04-30 是 2.43 億（審計轉述），2025-08-31 只有修繕與拆除兩項（1.1508 億＋0.2282 億）。2025-11 起的月報表只列 0923 計畫的明細，**沒有列 0403 各計畫的執行數**，只有 0403 匡列總額。
3. **公開日是推定值**。用的是檔名時間戳與 PDF CreationDate，縣府網站沒有版本紀錄。舊版頁面已被覆蓋，例如 0403 支出明細一覽表 2025-05-21 之前的版本、0923 支出頁在 2025-12-26 之前的版本、0403 月捐款頁 2025-05-02 之前是否有其他形式。可以用 Wayback Machine 補，本次沒有做。
4. **0206 的 60 案沒有逐案的核定日與結案日**。附表 A 沒有日期欄。0206 監督委員會自己的 19 次會議紀錄（中央社 2025-01-17 引楊華美：「0206善款委員會召開19次會議」）本次沒有找到。
5. **規則 a、c、e 沒有家戶層級的公開資料**。只能找到最接近的事例：0923 家電缺額對應 e；申請人丙、申請人乙、申請人甲的陳情對應 d。規則 a 完全無法用公開資料回測，只能說明「若保管人依 Kept 記帳」會怎樣。
6. **2025-01-17 之前有沒有質疑 0403 結餘的新聞**：只做了有限搜尋，不能排除更早的報導。
7. **口徑與數字不一致的地方**：
   - 開會次數：中央社 2025-01-17 寫 4 次，自由時報寫 3 次，自由時報 2025-03-30 寫 2 次。
   - 113-1 會議日期：紀錄寫 2024-09-20，另一份資料寫「113年8月20日」。
   - 0923 匡列：收支表寫 3億2,301萬4,500 元，計畫明細合計 3億2,109萬4,500 元，差 192 萬。
   - 公視的「4.2 億」是全專戶餘額，不是 0403 專屬餘額。這一點應同步更新 事實查核.md #2。
8. **既有筆記需要更正**：法規現況與缺口確認.md 寫 0923「支出明細一覽表 PDF 最後更新 114-12-26，只列 5 個計畫經費」。這只對那一個檔案成立。同一頁現在有 2025-11-30 到 2026-08-31 的月報表，列出核定數、已執行數與辦理情形。只是「匡列列為支出」的問題仍然存在。
